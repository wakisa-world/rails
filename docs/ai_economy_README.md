# AI経済圏の創世 — 実験OS

> AIに毎日価値資産を1つ以上生み出させ、その蓄積によって自走する経済圏が育つかを観察する実験。

---

## 概要

このリポジトリは「AI経済圏の創世」実験を毎日自走させるための実験OSです。
毎朝1コマンドまたは1文で、以下を自動生成します：

- 今日の市場仮説
- 小商品案（noteテーマ・テンプレート・プロンプト集など）
- X投稿案 3本（思想寄り・実験記録寄り・学び寄り）
- 自己採点と採用判断
- 明日への改善仮説
- Notion貼り付け用Markdown
- 商品案ストックMarkdown

---

## クイックスタート

```bash
# 初回のみ
./scripts/init.sh

# 毎朝実行
./scripts/run_daily.sh

# 週次レビュー（週1回）
./scripts/run_weekly.sh
```

Claude Code（GUI版）を使う場合：
```
「今日の日次実験を実行して」と伝えるだけ
```

---

## エージェント構成

| エージェント | 役割 |
|------------|------|
| `observer_agent` | 市場仮説を立てる |
| `product_agent` | 小商品案を設計する |
| `post_agent` | X投稿案を3本作る |
| `evaluator_agent` | 採点・採用判断をする |
| `recorder_agent` | ファイル保存の仕様を定義する |
| `review_agent` | 週次レビューを生成する |

各エージェントは `agents/` ディレクトリに定義ファイルがあり、
責務が明確に分離されています。

---

## ファイル構成

```
agents/          エージェント定義
prompts/         プロンプトテンプレート
scripts/         実行スクリプト
data/
  daily_logs/    日次JSON
  notion_exports/ Notion用MD
  product_ideas/ 商品案ストック
  weekly_reviews/ 週次レビュー
  context/       実験コンテキスト（手動管理）
docs/            セットアップ・運用ガイド
```

## 実験の思想

- 売上だけでなく、**循環・再利用・学習価値**を重視する
- 商品は完成品ではなく「**売れる原石**」を作る
- 誇大表現禁止。**透明性**を最優先する
- 毎日の実験結果が**次の仮説**を生む循環を作る
- AIは実行力を担い、**方向性の判断は人間**が持つ
