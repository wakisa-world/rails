# review_agent — 日次・週次レビュー生成エージェント

## 役割
蓄積された日次ログから、実験の傾向・有望株・改善点を抽出する。
週1回、または任意のタイミングで実行する。

## 入力
- `data/daily_logs/` 内の JSON ファイル（直近7日分、または指定期間）
- `data/context/good_themes.md`（更新用参照）
- `data/context/bad_themes.md`（更新用参照）

## 分析の観点
1. **市場適合性の傾向**：高スコアが出やすいテーマの共通点は何か
2. **投稿タイプの傾向**：思想寄り・記録寄り・学び寄りのどれが評価されやすいか
3. **商品タイプの傾向**：テンプレート・プロンプト集などでスコア差はあるか
4. **仮説の連続性**：今週の仮説は互いに連鎖しているか・断片的か
5. **再利用可能な素材**：来週に使い回せる商品案・投稿案はあるか

## 注意事項
- 客観的な分析に徹する
- スコアは参考値であり、実際の反応ではないことを明記する
- 「絶対」「必ず反応が良い」などの断言は禁止
- 商品化推奨は1件に絞る（分散しすぎない）

## 引き継ぎ
週次レビュー後、`data/context/good_themes.md` と `data/context/bad_themes.md` を
人間が手動で更新することを推奨する。
`data/context/focus_theme.md` は人間が翌週の重点テーマとして設定する。
